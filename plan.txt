Handoff Plan: Restore AnimePahe Auto-Downloader (defeat Cloudflare 403s)
1. Root cause (confirmed)
Every failing request in this app goes through plain httpx.AsyncClient (and requests in main.py). AnimePahe (.pw/.com) and Kwik (kwik.cx) sit behind Cloudflare + DDoS-Guard, which fingerprint the TLS ClientHello (JA3/JA4) and HTTP/2 frame order before headers are even read. Python's TLS stack is a dead giveaway, so the WAF returns 403 regardless of headers.
This is why the existing cookies.txt mitigation can't work: cf_clearance is cryptographically bound to the TLS fingerprint + IP + User-Agent of the client that solved the challenge. Replaying it from httpx (whose JA3 ≠ Chrome) is rejected.
Verified fix: route the whole flow through curl_cffi with impersonate="chrome", which reproduces a real Chrome TLS/HTTP2 fingerprint. A current, working reference downloader (GDjkhp/NoobGPT/animepahe.py (https://raw.githubusercontent.com/GDjkhp/NoobGPT/main/animepahe.py)) uses exactly this and needs no cf_clearance cookie at all — just impersonate='chrome' + a __ddg2_= cookie + referer, for the search API, play page, pahe.win, and the kwik.cx POST. The app's Kwik decode logic is already identical to that reference; only the transport must change.
2. Decisions locked (from your answers)
1. Full swap to curl_cffi: AnimePahe client, Kwik resolver, diagnostics, and the final downloader.
2. curl_cffi only — no headless browser/FlareSolverr. Keep cookies.txt as an optional manual fallback.
3. Domain: default → animepahe.com, keep ANIMEPAHE_BASE_URL override, add startup auto-detection across known mirrors.
4. Keep manual-import + cookies.txt as documented fallbacks; automatic flow becomes primary again.
3. curl_cffi ⇄ httpx API mapping (applies everywhere)
httpx	curl_cffi (curl_cffi.requests.AsyncSession)
httpx.AsyncClient(timeout=...)	AsyncSession(impersonate="chrome", timeout=...)
follow_redirects=True	allow_redirects=True
client.stream("GET", ...)	session.stream("GET", ...) (async ctx mgr)
response.aiter_bytes(n)	response.aiter_content(chunk_size=n)
await client.aclose()	await session.close()
client.is_closed	(none) — track our own flag
response.status_code/.text/.json()/.headers/.url	same
httpx.TimeoutException/TransportError/HTTPStatusError	curl_cffi.requests.exceptions.{Timeout,ConnectionError,HTTPError,RequestException}
Two critical correctness rules:
- Do NOT override User-Agent when impersonating (a UA that disagrees with the TLS fingerprint gets flagged). Let impersonate set UA + sec-ch-ua. Only set a UA if the user explicitly provides one.
- Downloader timeout trap: curl_cffi's timeout can act as a hard total cap that would abort large downloads. Use per-chunk asyncio.wait_for(...) for stall detection instead of a small total timeout (details in Phase 4). Flag this for verification.

Phase 1 — New shared transport module web/core/http_client.py (NEW FILE)
Centralizes impersonation config and version-tolerant exception imports so every module and the retry logic share one source of truth.
"""Shared curl_cffi HTTP layer with browser TLS impersonation.
All AnimePahe / Kwik / CDN traffic must go through curl_cffi so the TLS (JA3/JA4)
and HTTP/2 fingerprints match a real Chrome, which is what defeats the Cloudflare
/ DDoS-Guard 403s that plain httpx/requests cannot pass.
"""
from __future__ import annotations
import os
from curl_cffi.requests import AsyncSession
# Version-tolerant exception imports (module path changed across curl_cffi versions)
try:
    from curl_cffi.requests.exceptions import (
        RequestException as CurlRequestError,
        Timeout as CurlTimeout,
        ConnectionError as CurlConnectionError,
        HTTPError as CurlHTTPError,
    )
except Exception:  # pragma: no cover - older curl_cffi
    from curl_cffi.requests.errors import RequestsError as CurlRequestError  # type: ignore
    CurlTimeout = CurlConnectionError = CurlHTTPError = CurlRequestError
# Chrome by default; overridable if a fingerprint needs pinning (e.g. "chrome124").
IMPERSONATE_TARGET = os.environ.get("CURL_IMPERSONATE", "chrome")
DEFAULT_TIMEOUT = float(os.environ.get("HTTP_TIMEOUT", "30"))
# Retryable network-level errors (used by the downloader retry policy).
NETWORK_EXCEPTIONS: tuple[type[Exception], ...] = tuple(
    {CurlTimeout, CurlConnectionError, CurlRequestError}
)
def make_async_session(
    *,
    timeout: float | tuple[float, float] | None = DEFAULT_TIMEOUT,
    max_clients: int = 10,
    **kwargs,
) -> AsyncSession:
    """Create an impersonating AsyncSession. Pass allow_redirects per-request."""
    return AsyncSession(
        impersonate=IMPERSONATE_TARGET,
        timeout=timeout,
        max_clients=max_clients,
        **kwargs,
    )

async def ensure_base_url(self, client: AsyncSession) -> None:
    if self._base_url_resolved or self._base_url_locked:
        self._base_url_resolved = True
        return
    async with self._session_lock:
        if self._base_url_resolved:
            return
        for candidate in CANDIDATE_DOMAINS:
            try:
                resp = await client.get(candidate + "/", allow_redirects=True, timeout=10.0)
                if resp.status_code == 200:
                    final = str(resp.url).rstrip("/")
                    # keep scheme+host only
                    from urllib.parse import urlparse
                    p = urlparse(final)
                    self.base_url = f"{p.scheme}://{p.netloc}"
                    logger.info("Resolved AnimePahe base URL: %s", self.base_url)
                    break
            except Exception as exc:
                logger.debug("Candidate %s failed: %s", candidate, exc)
        self._base_url_resolved = True
2f. _ensure_session — simplify (curl_cffi persists cookies in its jar)
async def _ensure_session(self, client: AsyncSession) -> None:
    if self._session_ready:
        return
    async with self._session_lock:
        if self._session_ready:
            return
        try:
            await client.get(self.base_url + "/", headers=self._get_headers(), allow_redirects=True)
        except Exception as exc:
            logger.debug("Session warmup skipped: %s", exc)
        finally:
            self._session_ready = True
2g. _get_client / close
async def _get_client(self) -> AsyncSession:
    if self._client is not None and not self._client_closed:
        return self._client
    async with self._client_lock:
        if self._client is None or self._client_closed:
            self._client = make_async_session(timeout=self.timeout)
            self._client_closed = False
            await self.ensure_base_url(self._client)   # resolve domain first
            await self._ensure_session(self._client)
        return self._client
async def close(self) -> None:
    if self._client is not None and not self._client_closed:
        await self._client.close()
        self._client_closed = True
